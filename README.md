# Adult Media Mover — ناقل الأفلام والمسلسلات للكبار فقط

تطبيق سطح مكتب لـ Windows (Electron + Node.js + TypeScript) يفحص مجلدات مصادرك
المحلية أو على الشبكة (UNC)، يستعلم [TMDB](https://www.themoviedb.org) عن التصنيف
العمري لكل محتوى، ثم ينقل مجلدات المحتوى المُصنَّف للكبار إلى مجلد وجهة — وفق
مبدأ **Fail Closed** (لا نقل إلا بتصنيف موثوق من TMDB).

انظر [سجل التغييرات](CHANGELOG.md) و[دليل المستخدم](USER_GUIDE.md).

## المتطلبات

- Windows 10/11 (x64).
- مفتاح [TMDB API](https://www.themoviedb.org/settings/api) (مجاني).
- للتطوير فقط: Node.js 20+ و npm.

## التثبيت (للمستخدم)

1. نفّذ المثبّت `Adult.Media.Mover.Setup-<version>.exe` أو النسخة المحمولة
   `AdultMediaMover-Portable-<version>.exe` من مجلد `dist-release`.
2. شغّل التطبيق، أضف مجلدات المصادر، وحدد مجلد الوجهة.
3. أدخل مفتاح TMDB API (واختر حفظه على الجهاز إذا أردت — اختياري).
4. اضغط **«ابدأ الفحص والنقل»**.

## تنظيم المجلدات (مهم)

### الأفلام
ضع كل فيلم في مجلد باسمه (مع سنة اختيارية):

```
Pulp Fiction (1994)/
  pulp.mkv
Fight.Club.1999/
  fc.mkv
```

### المسلسلات (نمطان مدعومان)

**نمط الحاويات (موصى به):** مجلد جذر للسلسلة يضم مجلدات مواسم:

```
SpongeBob SquarePants/
  Season 01/  أو  الموسم 01/  أو  S01/
  Season 02/  أو  الموسم 02/
```

**نمط المسطح (مجلد واحد لكل سلسلة):**

```
Game.of.Thrones.S01/
  e1.mkv
```

يُكتشف تلقائياً: جذر سلسلة = مجلد كل أطفاله مجلدات مواسم (مثل `Season 1`,
`S01`, `الموسم 01`) ولا يُفلت حاويات المواسم كمرشّحين مستقلين — تُحفظ الهرمية
عند النقل. خيار **«الفحص المتكرر»** يُفعّل/يُطفئ النزول داخل مجلدات المصادر
للوصول إلى مجلدات المحتوى؛ كما يفصل جذر السلسلة عن مجلدات المحتوى المخفية
خلف عمق أعمق.

## المبادئ الأساسية

| المبدأ | التفصيل |
| --- | --- |
| **Fail Closed** | لا يُنقل أي مجلد إلا بعد أن يحسم TMDB تصنيفاً من قائمة الهدف (TV-MA, R, NC-17, X, 18+, ADULT, 18) وبنسبة ثقة ≥ 0.55. |
| **لا حذف أبداً** | الناقل (Mover) لا يقسّم ولا يحذف؛ النقل = إعادة تسمية/نقل المجلد كاملاً. |
| **Cross-Volume** | النقل بين مجلدات مختلفة (EXDEV) يُرفض تلقائياً ولا يُنفَّذ Copy→Delete. |
| **إيقاف آمن** | إيقاف الوظيفة يُكمل المجلد الحالي ثم يتوقف؛ يمكن إغلاق التطبيق أثناء التشغيل بتأكيد صريح. |
| **خصوصية المفتاح** | المفتاح لا يُسجَّل في السجل إطلاقاً، ويُحفظ على القرص فقط عند تفعيل الخيار الصريح. |
| **لا استبدال** | الوجهة لا تُستبدل أبداً؛ الاسم المتكرر يصبح `Name_1`, `Name_2` ... |

## السلوك التفصيلي (يعكس Requirements.md)

1. **الفحص**: مجلد المحتوى = مجلد يحتوي ملف فيديو مباشرة
   (mp4, mkv, avi, mov, wmv, flv, webm). الفحص المتكرر داخل المصادر افتراضي
   (قابل للإيقاف). أخطاء الفحص تُسجَّل دون إسقاط الوظيفة.
2. **تحليل الاسم**: يستخرج العنوان والسنة والموسم/الحلقات (يدعم صيغاً مثل
   `S01E01`, `Season 2`, سنوات منفصلة مثل `2019`, وأسماء عربية).
3. **التصنيف**: يبحث أولاً عن مسلسل (`TV Series`) ثم فيلماً، بنسبة ثقة؛
   تصنيف US أولوية، والبديل يُسجَّل في السجل عند غياب US.
4. **النقل**: يأخذ المصدر كامل المدة (رمز rename). كل مجلد يُعالج مرة واحدة؛
   أهم نتائج (processed/moved/skipped/errors) معروضة في لوحة الإحصائيات.
5. **توزيع الطلبات**: حد عالمي داخل التطبيق (~2.5 طلب/ثانية) يحمي من 429؛
   الأخطاء المؤقتة تُعاد 1s→2s→4s ثم تُتخطى؛ خطأ المصادقة (401/403) يوقف الوظيفة كاملة.

## الأمان

- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`.
- IPC بقائمة بيضاء عبر `contextBridge`؛ كل معالج يتحقق أن المتصل `file://`.
- لا توجد صلاحيات Node.js داخل الواجهة؛ كل التواصل عبر القنوات المعبّأة.
